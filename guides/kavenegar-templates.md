# Kavenegar templates

Generated by `npm run sms:check -- --templates` from
`civitechglobal-server/src/services/sms/templates.ts`. Do not edit by hand.

Submit each one in the Kavenegar panel (اعتبارسنجی / Verify → templates):
the **name** exactly as written, the **text** exactly as written, type SMS.
A text may only go out once its template is approved.

Rules every text follows: **no links** (the code refuses to send one), and
placeholders carry no spaces — multi-word values are joined with a
zero-width non-joiner, which reads as ordinary Persian.

## civiOtp

Used for: Every one-time code: insurance form, account phone check, password reset. (kind `otp`)

```
رایان تمدن جهان گستر
کد تأیید شما: %token
این کد تا ۵ دقیقه معتبر است. آن را به هیچ‌کس، حتی پشتیبانی ما، ندهید.
```

- `%token`: the 6-digit code

## civiPasswordChanged

Used for: The password was changed, or reset by SMS. Sent at once to a verified phone. (kind `passwordChanged`)

```
رایان تمدن جهان گستر
رمز عبور حساب کاربری شما امروز ساعت %token:%token2 تغییر کرد.
اگر این کار را شما انجام نداده‌اید، فوراً با پشتیبانی تماس بگیرید.
```

- `%token`: hour, e.g. 14
- `%token2`: minute, e.g. 30

## civiReceived

Used for: A visitor submitted a form: insurance, software project, consultation, CV. (kind `received`)

```
رایان تمدن جهان گستر
درخواست %token2 شما ثبت شد.
کد رهگیری: %token
با این کد می‌توانید در بخش «پیگیری درخواست» سایت، وضعیت درخواست خود را ببینید.
```

- `%token`: tracking code
- `%token2`: بیمه، پروژه، مشاوره or همکاری

## civiScheduled

Used for: Staff set the time of an insurance callback or a consultation. (kind `scheduled`)

```
رایان تمدن جهان گستر
زمان %token20 شما با کارشناس ما تعیین شد:
روز %token %token2، ساعت %token3:%token10
اگر این زمان برایتان مناسب نیست، با پشتیبانی تماس بگیرید.
```

- `%token`: day of the month, e.g. 25
- `%token2`: month, e.g. آبان
- `%token3`: hour, e.g. 14
- `%token10`: minute, e.g. 30
- `%token20`: تماس or مشاوره
