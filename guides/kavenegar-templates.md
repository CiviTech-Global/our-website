# Kavenegar templates

Generated by `npm run sms:check -- --templates` from
`civitechglobal-server/src/services/sms/templates.ts`. Do not edit by hand.

Submit each one in the Kavenegar panel (اعتبارسنجی / Verify → templates):
the **name** exactly as written, the **text** exactly as written, type SMS.
A text may only go out once its template is approved.

Rules every text follows: **no links** (the code refuses to send one), and
placeholders carry no spaces — multi-word values are joined with a
zero-width non-joiner, which reads as ordinary Persian.

## civiOtp

Used for: Every one-time code: insurance form, account phone check, password reset. (kind `otp`)

```
رایان تمدن جهان گستر
کد تأیید شما: %token
این کد را به هیچ‌کس ندهید.
```

- `%token`: the 6-digit code

## civiSecurity

Used for: Password changed or reset, two-step sign-in turned off, account deleted. Always sent to a verified phone. (kind `security`)

```
رایان تمدن جهان گستر
هشدار امنیتی: %token در حساب شما انجام شد.
اگر این کار شما نبوده، فوراً با پشتیبانی تماس بگیرید.
```

- `%token`: what happened, e.g. تغییر‌رمز‌عبور

## civiReceived

Used for: A visitor submitted a form: insurance, software project, consultation, CV. (kind `received`)

```
رایان تمدن جهان گستر
%token2 شما ثبت شد.
کد رهگیری: %token
برای پیگیری، این کد را در بخش «پیگیری درخواست» سایت وارد کنید.
```

- `%token`: tracking code
- `%token2`: what was submitted, e.g. درخواست‌بیمه

## civiScheduled

Used for: Staff set the time of an insurance callback or a consultation. (kind `scheduled`)

```
رایان تمدن جهان گستر
%token3 شما برای %token ساعت %token2 هماهنگ شد.
```

- `%token`: date, e.g. 1405/08/25
- `%token2`: time, e.g. 14:30
- `%token3`: what, e.g. تماس‌مشاور‌بیمه

## civiUpdate

Used for: Staff moved a visitor request on: proposal ready, CV decided. (kind `update`)

```
رایان تمدن جهان گستر
وضعیت درخواست %token: %token2
جزئیات را با همین کد در بخش «پیگیری درخواست» سایت ببینید.
```

- `%token`: tracking code
- `%token2`: new status, e.g. پیشنهاد‌آماده‌است

## civiAccount

Used for: Staff opened an account for a company or an expert. The password is never texted. (kind `account`)

```
رایان تمدن جهان گستر
حساب کاربری شما ساخته شد.
نام کاربری: %token
رمز عبور را حضوری دریافت کرده‌اید؛ پس از ورود آن را تغییر دهید.
```

- `%token`: username

## civiWaiting

Used for: A member has a new application, bid or purchase request. Off until SMS_MEMBER_ALERTS=true; at most one per member per 6 hours. (kind `waiting`)

```
رایان تمدن جهان گستر
%token تازه منتظر پاسخ شماست.
برای دیدن، وارد حساب کاربری خود شوید.
```

- `%token`: what, e.g. درخواست‌همکاری

## civiVerification

Used for: Staff decided an identity verification. Off until SMS_MEMBER_ALERTS=true. (kind `verification`)

```
رایان تمدن جهان گستر
نتیجهٔ احراز هویت شما: %token
جزئیات در حساب کاربری شماست.
```

- `%token`: تأیید‌شد or تأیید‌نشد
